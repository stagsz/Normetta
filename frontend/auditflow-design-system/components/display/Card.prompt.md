Surface container with an optional header row (title, subtitle, right-aligned action).

```jsx
<Card title="Clause progress" subtitle="ISO 9001:2015" action={<Button size="sm" variant="ghost">View</Button>}>
  …body…
</Card>
```

`padding` (none/sm/md/lg) and `elevation` (none/xs/sm/md) control density and lift.
