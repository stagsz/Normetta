Primary action button with petrol fill; use it for the single most important action in a view.

```jsx
<Button variant="primary" size="md" onClick={save}>Save assessment</Button>
```

Variants: `primary` (petrol, default), `secondary` (white + border), `ghost` (transparent), `danger` (red, destructive).
Sizes: `sm` · `md` · `lg`. Props: `iconLeft` / `iconRight` accept any node, `fullWidth`, `disabled`.
