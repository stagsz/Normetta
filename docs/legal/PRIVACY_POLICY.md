## 6. Data Security

### 6.1 Technical Measures
- **Encryption at rest:** All data in Supabase PostgreSQL is encrypted (AES-256)
- **Encryption in transit:** TLS 1.3 for all API and web traffic
- **Row-Level Security (RLS):** Database-level access controls ensure users only see their organization's data
- **Authentication:** Secure JWT tokens, bcrypt password hashing
- **Infrastructure:** SOC 2 Type II compliant hosting (Vercel, Supabase)

### 6.2 Organizational Measures
- Access controls: Only authorized personnel can access production systems
- Regular security audits and vulnerability scans
- Incident response plan for data breaches
- Employee training on data protection

### 6.3 Your Responsibility
- Keep your password secure (we recommend password managers)
- Enable two-factor authentication (available on Professional and Enterprise plans)
- Report suspicious activity immediately

**No system is 100% secure.** While we implement industry-standard protections, we cannot guarantee absolute security.

## 9. Your Rights (GDPR & Data Protection)

If you are an EU resident, you have the following rights:

### 9.1 Right to Access
Request a copy of your personal data (free, delivered within 30 days).

### 9.2 Right to Rectification
Correct inaccurate or incomplete data via account settings or by contacting us.

### 9.3 Right to Erasure ("Right to be Forgotten")
Request deletion of your data (we will comply unless legally required to retain it).

### 9.4 Right to Restriction of Processing
Request we limit how we use your data (e.g., during a dispute).

### 9.5 Right to Data Portability
Export your data in machine-readable format (JSON, CSV) via account settings.

### 9.6 Right to Object
Object to processing based on legitimate interests (e.g., marketing).

### 9.7 Right to Withdraw Consent
Unsubscribe from marketing emails or revoke consent at any time (does not affect prior processing).

### 9.8 Right to Lodge a Complaint
Contact your national data protection authority (e.g., Datainspektionen in Sweden).
