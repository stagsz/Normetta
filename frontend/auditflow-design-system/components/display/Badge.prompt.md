Pill label for counts, tags, and statuses.

```jsx
<Badge tone="brand" dot>Active</Badge>
<Badge tone="fail" variant="solid">3 overdue</Badge>
```

Tones: `neutral`/`brand`/`pass`/`obs`/`fail`/`info`. `variant` soft (tinted) or solid (filled). For ISO finding outcomes use **ConformanceBadge** instead.
