Labelled text input with hint/error states and optional leading icon.

```jsx
<Input label="Evidence reference" placeholder="e.g. QP-7.5 Rev 4" hint="Link a controlled document" />
<Input label="Auditor email" error="Enter a valid email" />
```

Pass `error` to switch the field into the nonconformity-red state. `size` is `sm`/`md`/`lg`.
